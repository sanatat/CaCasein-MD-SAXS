# راهنمای فارسی — پروژه Casein-MD-SAXS v2

## چه چیزی واقعاً انجام شد؟

این نسخه از توالی واقعی **β-casein A2 گاوی** استفاده می‌کند (۲۰۹ آمینواسید، ۵ سرین فسفریله). هر حدود ۱۰ اسیدآمینه در یک ذره درشت‌دانه ادغام شده‌اند. ۸ زنجیره × ۲۱ ذره = ۱۶۸ ذره. سه حالت قدرت جاذبه مؤثر پل‌های نواحی فسفریله (صفر، کم، زیاد) تعریف شد. برای هر حالت **سه اجرای مستقل MD با نویز حرارتی** اجرا شد و منحنی SAXS مصنوعی از مختصات خروجی محاسبه شد.

توجه: «کلسیم کم و زیاد» فقط به معنی **تغییر پارامتر جاذبه در مدل** است؛ هیچ یون واقعی کلسیم، غلظت برحسب مولار، مدل Martini یا شبیه‌سازی کامل میسل شیر وجود ندارد.

## نتایج اجراشده

- قدرت جاذبه صفر: **۱۲٫۰۷ ± ۱٫۸۸** تماس بین نواحی فسفریله زنجیره‌های مختلف.
- قدرت جاذبه کم: **۱۷٫۶۹ ± ۰٫۶۸** تماس.
- قدرت جاذبه زیاد: **۲۲٫۵۱ ± ۲٫۰۷** تماس.

خطای ± در اینجا انحراف معیار میانگینِ **سه اجرای مستقل** است؛ اثبات معناداری آماری یا پیش‌بینی اثر یون کلسیم در آزمایش واقعی نیست. هر سه حالت در این بازه کوتاه همچنان ۸ زنجیره متصل داشتند.

## اجرای نسخه دوم روی لینوکس

```bash
cd ~/Downloads/CaCasein-MD-SAXS/v2_sequence_calcium
python3 -m venv .venv
source .venv/bin/activate
pip install -r ../requirements.txt
python -m pytest -q tests
python casein_v2.py --steps 3200 --replicas 3 --stride 100 --out new_results
python analyze_local_contacts.py --results new_results
```

## فایل‌ها

- `casein_v2.py`: موتور MD، پتانسیل نیروها، تحلیل خوشه و SAXS مصنوعی.
- `analyze_local_contacts.py`: تعداد تماس ناحیه‌های فسفریله و میانگین/انحراف معیار سه تکرار.
- `experimental_data_helper.py`: دانلود فایل اصلی SAXS منتشرشده در Zenodo و امکان نمایش مقایسه اکتشافی، فقط بعد از تعیین مقیاس طول معتبر.
- `results/02_saxs_synthetic.png`: نمودار SAXS مصنوعی.
- `results/05_phosphosite_contact_replica_sd.png`: نمودار تماس نواحی فسفریله.
- `results/*.npz`: تراژکتوری شبیه‌سازی‌های واقعی.

داده آزمایشگاهی ۲۰۲۶ موجود است اما نمونه‌اش **شیر در حال ژل‌شدن با آنزیم** است؛ با شرایط شبیه‌سازی ما انطباق ندارد و نباید آن را اعتبارسنجی مدل بنامیم. لینک: https://zenodo.org/records/22044394
