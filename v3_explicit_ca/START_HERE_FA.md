# راهنمای فارسی نسخه سوم CaCasein-MD-SAXS

## چه کار انجام شده؟
- ۴ زنجیره از β-casein A2، هر زنجیره به ۲۱ ذره تبدیل شده است.
- یون‌های Ca²⁺ به‌صورت ذرات متحرک دارای بار مثبت دو در مدل ساده اضافه شده‌اند.
- چهار حالت، هر کدام سه تکرار مستقل، مجموعاً ۱۲ شبیه‌سازی کوتاه Langevin MD اجرا شده است.
- پس از آن، از مختصات پروتئین‌ها منحنی SAXS مصنوعی، توزیع فاصله بین ذرات، تعداد اتصالات بین زنجیره‌ها و نمودارها تولید شده است.
- نتایج در `results/` قرار دارند.

**نکته:** این مدل Martini واقعی نیست. از واحدهای کاهش‌یافته استفاده می‌کند. عدد ۸ یا ۱۶ یون معادل هیچ غلظت واقعی بر حسب mM نیست. جایگذاری اولیه یون‌ها نزدیک جایگاه‌های فسفریله می‌تواند نتایج را تحت تأثیر قرار دهد. شبیه‌سازی کوتاه بوده و به تعادل‌رسیدن آن ثابت نشده است.

## اجرای Linux Mint

```bash
cd ~/Downloads
unzip CaCasein-MD-SAXS-v3-complete.zip
cd CaCasein-MD-SAXS/v3_explicit_ca
python3 -m venv .venv
source .venv/bin/activate
pip install -r ../requirements.txt
python -m pytest -q tests
python explicit_ca_md.py --steps 2400 --replicas 3 --stride 80 --out my_results
```

## نتیجه چه چیزی را ثابت می‌کند؟
فقط اینکه یک مدل ساده با ذرات متحرک کلسیم و مکان‌های حساس به فسفریلاسیون می‌تواند اثر پارامتر برهم‌کنش اختصاصی را بر تماس‌های کلسیم–پروتئین و منحنی پراکندگی شبیه‌سازی‌شده نشان دهد؛ نه میزان واقعی جذب کلسیم، ساختار طبیعی میسل شیر یا SAXS تجربی.

## قدم واقعی بعدی
به‌دست‌آوردن پارامترهای معتبر برای phosphoserine و Ca²⁺ در Martini3، آماده‌سازی انسامبل ساختاری پروتئین، GROMACS و اعتبارسنجی با SAXS منطبق. جزئیات در `MARTINI3_UPGRADE_PLAN.md`.
